# Report Outline

Use this skeleton to structure your evaluation report. Each section lists the
output files and figures to cite.

---

## 1. Introduction

- Scenario: last-mile delivery dispatch for a courier company
- Two tasks: sorting delivery orders by various keys; shortest-path routing
  on a synthetic road network
- Objective: compare algorithms empirically and theoretically, recommend the
  best for each task

## 2. Scenario and Dataset Description

- Delivery orders: fields (order_id, priority, deadline, distance_km,
  parcel_weight, zone_id); generated by `src/generators/orders.py`
- Road network: grid-based sparse graphs and random dense graphs;
  generated by `src/generators/graphs.py`
- Justify realism of synthetic data
- **Cite:** `environment.json` for machine specs and seeds

## 3. Evaluation Criteria (defined before experiments)

- Sorting criteria and weights: see `src/analysis/criteria.py`
- Graph criteria and weights: same file
- Explain why each criterion matters for the scenario
- **Cite:** `criteria.py` for exact weights
